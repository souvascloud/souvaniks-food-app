# 🍔 Souvanik's Food App

A modern **Food Ordering UI** built with **React + Vite** while learning core React concepts such as **Components, JSX, Props, State, Event Handling, and Reusable UI Design**.

Inspired by popular food delivery applications like **Swiggy** and **Zomato**, this project is being developed step by step to understand React fundamentals before moving to advanced concepts.

---

##  Preview

A clean and responsive food ordering homepage featuring:

- Modern Header
- Search Bar
- Category Chips
- Restaurant Cards
- Favorite (Heart) Interaction
- Stylish Footer

> *(Project is actively being developed and new features are added incrementally.)*

## 🛠 Installation

Clone the repository.

```bash
git clone https://github.com/souvascloud/souvaniks-food-app.git
```

Move into the project folder.

```bash
cd souvaniks-food-app
```

Install dependencies.

```bash
npm install
```

Start the development server.

```bash
npm run dev
```
